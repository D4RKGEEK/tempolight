It follows the song, not just the volume

Most music-reactive lighting reacts to how loud the music is right now. Tempolight knows where the beat is, which part of the song you are in, and what comes next.

Every light flashes on the same beat

The new beat tracker lands on 91% of beats in the test songs, up from 64%. Each light gets its own delay, so Hue, WiZ and WLED flash within a few milliseconds of each other.

The room builds toward the drop

While listening live, Tempolight hears a drop coming 3 to 5 seconds ahead, even in a song it has never heard. The lights get brighter and faster, dip on the last beat, then flash.

Set up in 2 minutes

Every way runs the same app and keeps your settings in the same place. Start it and the setup wizard takes you through five steps.

  1. Find your lights on the network
  2. Pick a room layout
  3. Fix the timing with one tap
  4. Play a test song

With Node.js 20 or newer. No download and nothing else to install.

npx tempolight --open

One file with Node.js inside, for Windows, macOS (a .dmg) and Linux. Download the latest release, or use a package manager:

brew install d4rkgeek/tempolight/tempolight
winget install D4RKGEEK.Tempolight

Images for amd64 and arm64. Host networking lets it find your lights and stream to them.

docker run -d --name tempolight --network host -v tempolight:/data --restart unless-stopped ghcr.io/d4rkgeek/tempolight

Flash the image from the releases with Raspberry Pi Imager, join the Tempolight-Setup hotspot from your phone to pick your Wi-Fi, then open tempolight.local. Pi 5, 4, 3, Zero 2 W, 400 and 500. Already on Pi OS:

curl -fsSL https://raw.githubusercontent.com/D4RKGEEK/tempolight/main/install/install.sh | sh -s -- --service

In Home Assistant: Settings → Add-ons → Add-on store → ⋮ → Repositories. Add this repository, then install Tempolight. With the Mosquitto add-on it shows up by itself.

https://github.com/D4RKGEEK/tempolight

What people ask first

Do I need to flash anything to my ESP32?

No. Stock WLED works. Tempolight streams with DDP, which WLED supports out of the box.

Can it hear Spotify, YouTube or Apple Music?

Yes. Sync with Spotify follows Spotify's exact position. For anything else it listens to this computer's sound or a microphone, and remembers songs it has heard.

The lights are a little behind the music.

Use the one-tap timing fix on the Music page: it plays clicks and listens with the microphone. Bluetooth speakers usually need −150 to −250 ms.

How many LEDs can it drive?

Thousands. About 7% of one CPU core drives 700 LEDs at 60 frames a second. Wi-Fi is usually the limit, so big rooms do best on wired controllers.

Is it safe for photosensitive epilepsy?

Turn on Photosensitive-safe mode: at most three big flashes a second (WCAG 2.3.1). Night mode turns strobes off.

Does it need the cloud or an account?

No. Everything runs on your network. Spotify's Web API, shared beat maps, Twitch and Discord connect only when you turn them on.
